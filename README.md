# Advanced Machine Learning Labs

My lab work from ECEGR 5760 Advanced Machine Learning, Seattle University,
Winter 2026. All my own work.

## What this is

A series of labs and exercises on Bayesian inference and machine learning:

- **Bayesian inference and MCMC** (`bayesian-inference-mcmc/`) — a series of
  lab explorations on Bayesian inference and Markov-chain Monte Carlo
  simulation
- **Bayesian regression** (`Lab2_Bayesian_Regression_Olympic100m.pdf`) —
  Bayesian regression on Olympic 100m sprint data, with the sequential-lines
  and prior/posterior-contour figures in `figures/`
- **Textbook exercises** (`winn-exercises/`) — worked exercises from the course
  text, chapters 1 and 2
- **Factor graphs** (`factor-graphs/`) — factor-graph summary and exercises
- **Decision analysis** (`In-class_Exercise_2_Decision_Analysis.pdf`) — an
  in-class exercise on making a decision under uncertainty, using prior
  probabilities

A few of the rendered lab write-ups aren't here. Four of them had my laptop's
file paths baked into the output — my Windows username and local folders
showing up in the rendered pages — so I left them out: the MCMC inference lab
write-up, the February 12 lab write-up, and two of the textbook-exercise
write-ups. They covered the same kind of work as the rest of the labs —
running MCMC samplers, working through the textbook problems — just with my
file paths printed in them. The write-ups that are here cover the rest.

## Tools

Python (NumPy, SciPy, Matplotlib), MATLAB (Olympic Bayes lab — the lab script
itself was course-provided and is not included here).
